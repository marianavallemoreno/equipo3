## 🌐 Pasos para Publicar en GitHub Pages

1. Descomprime este archivo `.zip` en tu computadora.
2. Crea un nuevo repositorio público en GitHub llamado `eclipse-team3`.
3. Sube el contenido de esta carpeta al repositorio.
4. En GitHub, ve a **Settings** -> **Pages**.
5. Selecciona la rama `main` / `master` y la carpeta `/ (root)`.
6. Guarda los cambios. Tu sitio estará en línea en pocos segundos.
